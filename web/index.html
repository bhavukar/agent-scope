Time-Travel Replay

02

Sub-Millisecond Overhead

In-memory ring buffer tracing adds less than 0.02ms latency per tool call. No external cloud dependencies or blocking HTTP egress.

03

Model Context Protocol Native

Drop-in compatibility with any standard MCP client or server. Works instantly with Claude Desktop, Cursor, and custom JSON-RPC agent loops.
